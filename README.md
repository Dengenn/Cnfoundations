# CN Foundations

A static informational website for the Sir Chris Nkwonta Foundation.

## Overview

- HTML, CSS, and JavaScript-based site
- Includes pages for About, Services, Mission, Projects, Scholarships, News, and Contact
- Designed for nonprofit and community outreach

## Preview

Open `index.html` in a browser to view the site locally.

## Files

- `index.html` — homepage
- `about.html` — foundation story
- `services.html` — available services
- `mission.html` — mission statement
- `projects.html` — project highlights
- `scholarships.html` — scholarship details
- `news.html` — updates and announcements
- `contact.html` — contact form and support links
- `css/style.css` — styles
- `js/` — interactive page scripts

## Notes

This repository is private and not ready for publication yet.
